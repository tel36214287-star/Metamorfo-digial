               # Metamorfo-digial

               Metamorfo Digital

Inspirado no filme Os Observadores (Dakota Fanning)

O Metamorfo Digital é um script que muda de forma, alternando entre código executável (.py) e texto (.txt).
Cada execução é uma metamorfose: o arquivo se transforma, registra seu ciclo e imprime mensagens no terminal.

Este projeto é um experimento poético de software: assim como os personagens observam e mudam, o script se observa e se altera.


---

Conceito

Identidade fluida: o mesmo arquivo alterna entre código e texto.

Memória interna: cada metamorfose incrementa um contador em _count.txt.

Autonomia: o arquivo se renomeia sozinho e decide sua próxima forma.

Segurança: loops finitos controlados; nada roda em segundo plano.



---

Uso

Preparação no Termux

nano metaformo.py        # cole o código Python do metamorfo
chmod +x metaformo.py    # torna executável
rm metaformo_count.txt    # opcional, reseta contador

Execução

python metaformo.py

Possíveis Extensões

Diário poético dentro do próprio arquivo, registrando cada metamorfose.

Loop infinito controlado para simular ciclos contínuos de observação.

Integração com GIFs ou logs gráficos para visualização da metamorfose.



---

Conclusão

O Metamorfo Digital é uma metáfora viva: mesmo sendo o mesmo arquivo, ele muda de identidade, registra sua própria história e interage com o usuário de maneira poética.
Como em Os Observadores, há uma vigilância e transformação constante — o script se vê, se transforma, e deixa rastros de si mesmo.
